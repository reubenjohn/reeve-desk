## When to Create a New Pattern

A pattern earns its own file when:
- The same issue has occurred **2+ times**
- A behavior has been observed across **3+ days**
- A workaround or fix needs to be **remembered across sessions**

Keep patterns concise and actionable — link to Diary entries for raw details.
