# Knowledge

Everything Reeve "knows" — distinct from directives (Goals, Responsibilities, Preferences, Tasks).

## Contents

| Directory | What's Here | When to Check |
|-----------|------------|---------------|
| [Diary/](Diary/README.md) | Activity logs, hourly pulse records, observations | Every pulse (for continuity + hour-aligned tasks) |
| [Diary/Patterns/](Diary/Patterns/README.md) | Recurring behavioral & system patterns | When investigating issues or detecting trends |
| [Diary/Investigations/](Diary/Investigations/) | Deep-dive research & debugging sessions | When revisiting past technical work |
| [Infrastructure/](Infrastructure/README.md) | MCP servers, health checks, runbooks | Every hourly pulse (quick check) + when things break |
| [Relationships/](Relationships/README.md) | People, contacts, interaction tracking | Morning briefings + relationship check-ins |

## Quick Discovery

**Something broke?** → [Infrastructure/README.md](Infrastructure/README.md) for health checks, then [Infrastructure/Runbooks/](Infrastructure/Runbooks/) for the specific service.

**Need context from a past day?** → [Diary/YYYY-MM/](Diary/) organized by month.

**Who is someone / when did we last talk?** → [Relationships/README.md](Relationships/README.md)

**Seen this problem before?** → [Diary/Patterns/](Diary/Patterns/README.md) for recurring issues.

**Deep technical investigation?** → [Diary/Investigations/](Diary/Investigations/) for past research.
